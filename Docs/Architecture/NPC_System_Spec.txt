Visual + Animation (Constrained)

Supported locomotion states: Idle, Walk, Run (only).

Directional sprite sequences: Down/Left/Right/Up (as you already do), but Blink is not used for Up.

Blink Overlay (Final Rule)

Idle breathing uses an 8-frame loop.

Blink:

Triggers only when current displayed Idle frame is index 0 (the 1st sprite).

Blink replaces that single frame with a blink frame for the current facing direction:

Blink_Down, Blink_Left, Blink_Right

If facing Up: do nothing (skip blink)

Blink is a one-shot overlay; after showing the blink frame briefly, resume the normal Idle loop.

Blink is executed only while in Idle state (no blink during Walk/Run in v1.1).

small radius

Time-of-day Integration

NPC system must read time-of-day via ITimeOfDayService and respond to segment changes.
Narrative may optionally pause/hold time using your existing handle patterns.

Narrative Priority and Control

Introduce an interrupt policy concept in NPCController:

Normal: autonomy allowed (route + micro-wander + blink overlay eligible)

Suppressed: autonomy allowed but micro-wander disabled and blink reduced/disabled

Frozen: autonomy disabled; movement canceled

Sequencer claiming model:

Hard claim → Frozen

Soft claim → Suppressed (finish current micro-action, then yield)

Must be checkpoint/resume safe and deterministic when controlled by sequences.
