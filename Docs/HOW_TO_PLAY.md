# How To Play

1. Launch the project in Unity and load a combat-enabled scene.
2. Connect/select your wallet path (or use demo/stub mode if configured).
3. Enter encounter flow and start a battle.
4. On your turn:
   - Navigate the action selector (Fight/Swap/etc.).
   - Pick a move.
   - Select targets when prompted, then confirm.
5. Defeat enemy Chainlings by managing AP, move targeting, and swap timing.
6. Continue progression via capture/profile systems if enabled in your setup.

## Controls (General)
- Navigate: stick/D-pad or configured UI navigation.
- Confirm: primary confirm action.
- Cancel: back/cancel action.
- Info: move details when available.

## Notes
- Devnet + RPC config must be set before live-chain actions.
- If blockchain services are unavailable, use stub/demo mode for gameplay iteration.
