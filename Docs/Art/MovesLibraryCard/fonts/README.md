# Fonts (do not duplicate)

Bake library-card PNG text from the repo TrueType file. Do **not** copy the font into this folder.

| Role | Path |
|---|---|
| PNG compositor (this kit) | `Assets/Sprites/UI/PixeloidSans.ttf` |
| Optional bold | `Assets/Sprites/UI/PixeloidSans-Bold.ttf` |
| In-game TMP SDF only | `Assets/Resources/TextMesh Pro/Fonts/PixeloidSans SDF.asset` |

Unity inventory UI continues to use the TMP SDF atlas. NFT/export PNGs must outline PixeloidSans into pixels so wallets do not need the font file.
