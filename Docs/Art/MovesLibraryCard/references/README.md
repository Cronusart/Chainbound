## Stamped-ink texture (visual only)

A distressed rubber-stamp / letterpress alphabet was used as **look-dev reference** during v1. That stock image is **copyrighted** and is **not** stored in this repository.

Compositor v1 approximates the look with noise + erode on PixeloidSans glyphs (`tools/library-card-render/render.py`). Do not paste third-party alphabets into layers.
