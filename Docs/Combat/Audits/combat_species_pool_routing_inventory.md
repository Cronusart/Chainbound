- Pool rows classified `full` route through standard damage/status/stage/heal fields, resolve profiles, or typed utility payloads.
- `special_family` is intentional resolver-family routing, not an invitation to add new move-ID branches.
- `hardcoded_defId` rows are retained compatibility routes and remain post-beta migration candidates.
