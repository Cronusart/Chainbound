0. Purpose
===============================================================================

This specification defines move modifiers — attributes that can be applied
to baseline moves to alter their behavior, damage type, stat scaling,
hit count, or other properties.

NAMING CONVENTION (v1.1):
Modifiers do NOT have display names. In-game, rarity is communicated via UI
colour coding (see Section 11.2). This spec uses section-based IDs (e.g., §2.1-a)
for internal cross-referencing only; these IDs are NOT shown to the player.

IMPORTANT (v1.1):
- AP cost reduction modifiers are BANNED. AP cost is tied to inherent power.
- The move system does not use cooldowns. No modifier may reference them.
- All modifiers must declare Active or Passive scope (see Section 1.3).
- Effect values use ranges where possible; fixed values reserved for caps only.

DESIGN PRINCIPLES:
- Modifiers add build depth without invalidating baseline moves
- Rarity gates power; higher rarity = more impactful modifiers
- Stacking rules prevent broken combinations
- Modifiers are ADDITIVE to baseline, never replacing core function
- Drop rates tie into Acquisition Spec (04)
- No modifier may bypass chemistry trigger rules or force direct chemistry statuses

1. Modifier Categories
===============================================================================

1.1 Category Overview

| Category      | Code | Effect Type                              | Slot Cost | Scope        |
|---------------|------|------------------------------------------|-----------|--------------|
| Potency       | POT  | Numeric bonuses (power, accuracy, crit)  | 0         | Active       |
| Efficiency    | EFF  | AP refund chance, bonus action rolls     | 0         | Active       |
| Augmentation  | AUG  | Extra hits, priority                     | 1         | Active       |
| Transmutation | TRX  | Type change, stat substitution           | 1         | Active       |
| Trigger       | TRG  | Conditional effects, on-hit bonuses      | 0         | Active       |
| Synergy       | SYN  | Team-based or combo-based effects        | 0         | Active/Vary  |

SLOT COST: Some powerful modifiers consume an extra move slot when equipped.
A Chainling with 16 slots equipping 2 AUG modifiers effectively has 14 move slots.

1.2 Modifier Rarity Tiers

| Tier      | Effect Potency    | Baseline Vending Weight |
|-----------|-------------------|-------------------------|
| Common    | Minor (+5-10%)    | 45%                     |
| Uncommon  | Moderate (+10-15%)| 30%                     |
| Rare      | Notable (+15-25%) | 17.5%                   |
| Epic      | Major (+25-35%)   | 5%                      |
| Legendary | Signature effect  | 2%                      |
| Mythic    | Build-defining    | 0.5%                    |

NOTE:
- Modifiers do not drop directly from star-up or mastery.
- Entangled affects ordinal farming, not modifier odds directly.
- Event-limited modifiers may use a separate distribution skew (see Section 9.2).

1.3 Active vs Passive Scope

Every modifier must declare one of two scopes:

| Scope   | Meaning                                             | Frequency   |
|---------|-----------------------------------------------------|-------------|
| Active  | Applies ONLY to the move it is attached to   | Most common |
| Passive | Applies globally to the Chainling as a permanent aura | Rare       |

RULES:
- Most modifiers are Active (per-move).
- Passive modifiers should be low-impact or have meaningful tradeoffs.
- Each modifier entry in this spec includes its scope in the Scope column.
- Active modifiers only fire when the attached move is used.
- Passive modifiers are always on while the modified move is equipped.

8. Stacking and Combination Rules
===============================================================================

8.1 Global Stacking Limits

| Rule                                           | Limit                    |
|------------------------------------------------|--------------------------|
| Total modifiers per move                | 3 maximum                |
| Power modifiers (§2.1) per move         | 1 maximum                |
| Accuracy modifiers (§2.2) per move      | 1 maximum                |
| Crit modifiers (§2.3) per move          | 1 maximum                |
| AP refund modifiers (§3.1) per move     | 1 maximum                |
| Bonus action modifiers (§3.2) per move  | 1 maximum                |
| Slot-consuming modifiers (AUG/TRX) per inscrip.| 1 maximum               |
| On-hit triggers (§6.1) per move         | 2 maximum                |
| On-crit triggers (§6.2) per move        | 1 maximum                |
| Conditional triggers (§6.3) per move    | 2 maximum                |
| On-swap-in modifiers (§6.4.1) per Chainling    | 1 maximum (global)       |
| On-swap-out modifiers (§6.4.2) per Chainling   | 1 maximum (global)       |
| Stat substitution (§5.2) per Chainling         | 2 maximum (global)       |

8.2 Forbidden Combinations

The following modifier combinations are INVALID on the same move:

| Modifier A                     | Modifier B                      | Reason                           |
|--------------------------------|---------------------------------|----------------------------------|
| Any AUG (§4)                   | Any TRX (§5)                    | Cannot stack slot-cost modifiers |
|                                |                                 | on the same move          |
| Multi-hit §4.1-a               | AOE bounce §4.2-a               | Cannot combine multi-hit + AOE   |
| Bonus action repeat §3.2-a     | Any other §3.2 bonus action     | Only one bonus action per move   |
| On-crit +25% power §6.2-c      | Any other §6.2 on-crit          | Exclusive on-crit trigger        |
| Type infusion §5.1-a           | Second type infusion §5.1-a     | Only one type change per move    |
| Any on-swap-in §6.4.1         | Any other on-swap-in §6.4.1    | Only one swap-in modifier per    |
|                                |                                 | Chainling                         |
| Any on-swap-out §6.4.2        | Any other on-swap-out §6.4.2   | Only one swap-out modifier per   |
|                                |                                 | Chainling                         |

NOTE: AUG + TRX are forbidden on the SAME move only. A Chainling may have
one move with an AUG modifier and a different move with a TRX modifier.
Slot costs are tracked per move.

8.3 Modifier Inheritance

- Modifiers apply to the specific move instance, not globally
- If an move is replaced, modifiers are lost
- Modifiers cannot be transferred between moves
- Duplicate moves with different modifiers are considered unique

Entangled (bootleg) Chainlings do NOT receive direct modifier-rate bonuses.

Entangled affects modifier acquisition indirectly by:
- improving ordinal farming odds
- improving ordinal rarity outcomes
- making premium source moves more likely before vending is used

11. UI and Display
===============================================================================

11.1 Modifier Display Format

Modifiers do not have display names. They are represented in the UI as:
- Effect-description icons/badges attached to the move card
- Colour-coded by rarity (see §11.2)
- Hoverable for full tooltip

Display format:
[Move Name] + [Effect Icon 1] + [Effect Icon 2] + [Effect Icon 3]

Example: "Baseline Striker" with three coloured modifier badges indicating
+12-18% power (blue/Rare), heal 10-15% on hit (blue/Rare), and
+25-35% dmg if target HP < 50% (blue/Rare).

11.2 Color Coding by Rarity

| Rarity    | Color    | Hex Code  |
|-----------|----------|-----------|
| Common    | Gray     | #9E9E9E   |
| Uncommon  | Green    | #4CAF50   |
| Rare      | Blue     | #2196F3   |
| Epic      | Purple   | #9C27B0   |
| Legendary | Orange   | #FF9800   |
| Mythic    | Red/Gold | #F44336   |

11.3 Tooltip Information

Modifier tooltips must display:
- Rarity tier (colour-coded)
- Effect description (with range if applicable)
- Scope (Active or Passive)
- Restrictions (if any)
- Stacking category (e.g., "Power — 1 per move")
- Source (how to obtain: Vending / Event / Achievement)
